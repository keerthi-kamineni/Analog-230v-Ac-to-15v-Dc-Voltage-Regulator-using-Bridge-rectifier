# Analog-230v-Ac-to-15v-Dc-Voltage-Regulator-using-Bridge-rectifier
240V AC to 15V DC Power Supply using Bridge Rectifier

This project demonstrates the design and analysis of a regulated DC power supply that converts 240V AC input into 15V DC output using a bridge rectifier, filter, and voltage regulator.



Project Overview

The objective of this project is to convert high-voltage AC supply into a stable and usable DC voltage suitable for electronic devices.

The system includes:
- Step-down transformer
- Bridge rectifier
- Filter capacitor
- Voltage regulator


Working Principle

1. Step-Down Transformer
- Reduces 240V AC to a lower AC voltage (typically 12V–18V)

2️. Bridge Rectifier
- Converts AC to pulsating DC using four diodes
- Allows full-wave rectification

3️. Filter (Capacitor)
- Smooths the pulsating DC
- Reduces ripple in the output

4️. Voltage Regulator
- Provides constant 15V DC output
- Maintains stability despite input fluctuations



5. Circuit Components

- Transformer (240V/12V or 15V)
- Bridge Rectifier (4 diodes or IC)
- Capacitor (1000µF)
- Voltage Regulator (IM7815)
- Load resistor


6. Output Characteristics

- Input: 240V AC  
- Output: ~15V DC  
- Ripple reduced using capacitor filtering  
- Stable output using voltage regulator  



7. Key Concepts Covered

- AC to DC conversion  
- Fullwave rectification  
- Ripple filtering  
- Voltage regulation  
- Power supply design
